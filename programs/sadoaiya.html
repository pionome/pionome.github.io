Sadoaiya

GMO Model Editor for Persona 4 Golden

Download Sadoaiya

Key Features

  • P4G Optimization: Applies necessary changes for model compatibility in P4G PC.
  • Format Conversion: Converts to text format for easy manual editing.
  • AMD Support: Importing and extracting AMD files with precision.
  • Texture Management: Extract and import textures seamlessly.
  • Array Customization: Change format of arrays to meet specific modding requirements.
Note: This tool handles model compatibility for P4G, not the initial 3D modeling or rigging process.

Model Import Process

Prerequisites

You will need the .NET 6.0 Runtime, Sadoaiya, and PSP Converter Tools.

Step-by-Step

  1. Export your model as FBX (Preferably 2009 ASCII).
  2. Crucial: Rotate your model 180 degrees on the Z axis.
  3. Run: gmoconv.exe {yourFBX} -S to get a GMS file.
  4. Edit the GMS text if needed, then run: gmoconv.exe {yourGMS}.
  5. Finalize for P4G by dragging the GMO onto sadoaiya.exe.
